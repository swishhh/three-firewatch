# CLAUDE.md — firewatch-py

Python/Panda3D remake of the three.js scene in the parent dir. Work only inside `firewatch-py/`; the parent JS app is reference only (assets `../obj`, `../sound` are shared, read-only). README.md has user-facing detail; don't read it unless needed.

## Run / test
- Run: game `.venv/bin/python main.py`, editor `.venv/bin/python editor.py`; both `[--world NAME] [--fps N] [--vsync|--no-vsync]`. Deps pinned in requirements.txt (panda3d, panda3d-gltf, numpy).
- System python lacks ensurepip; venv was made with `--without-pip` + pip.pyz. Use `.venv/bin/python -m pip`.
- No test suite. Lint: `.venv/bin/python -m pyflakes main.py firewatch`.
- Verify visually offscreen (never pop windows on the user's desktop): before importing the app, `load_prc_file_data('', 'window-type offscreen\naudio-library-name null')`, set `firewatch.settings.FILE` AND `firewatch.world.document.SAVES_DIR` to scratch paths (else tests overwrite the user's settings.json and world saves — the user edits worlds in `saves/`). Offscreen has no mouse: the editor installs a dummy MouseWatcher; stub `editor.terrain_hit`/`pointer`/`over_gui` to drive tools. Step with `app.task_mgr.step()`, save with `app.win.save_screenshot(Filename.from_os_specific(path))`, then view the PNG.

## Architecture (`firewatch/`)
- `app.py` ShowBase(mode='game'|'editor'): loads settings → PRC → `shading.init` → `scene.draw` (per-mode component lists in `scene.py`, each module has `draw(app)`) → `pipeline.init_pipeline`. Frame pacing in `_limit_frame_rate` (fps_cap -1 = display rate, unfocused cap). Per-frame callbacks via `update.add_update_callback(fn(dt))` / `remove_update_callback`; shared objects via `registry.add/get`.
- `settings.py`: schema (Tabs/Sections/Setting with default + `js` value), presets, `TIME_KEYFRAMES`. `gfx.*` persist to `settings.json` (+ `_meta`: version, active world); `env.*` belong to the world save (`store.environment()/set_environment()`). API: `settings.get/set/update/subscribe(cb, prefix)/unsubscribe`. New setting = add to schema; UI (`ui/settings_panel.py`, F1, built from `ui/widgets.py` rows) is generated from it.
- World (`world/`): `document.py` save format (saves/<name>/world.json + terrain.npz, Panda coords; record templates `new_object/new_foliage/new_water`, `fill_defaults` upgrades old saves), `legacy.py` builds 'default' from the JS MAP arrays, `runtime.py` World (load/autosave/listeners `notify(section)`, snapshot/restore for undo, distance-cull node list), `terrain.py` heightfield+paint+water mask in 64 culled chunks with per-chunk LOD (edges snapped to coarser neighbors), brushes, raycast; `foliage.py` brush groups baked per 25 m cell; `water.py` mask meshes + `shaders/water.*` (needs the depth prepass; soft edge from blurred mask in vertex alpha); `entities.py` WorldObject (root→content, prefabs CampfireRig/Bird, 2.5D collision shapes incl. 'mesh' footprint); `colliders.py` standalone box/cylinder colliders (world.json 'colliders'; editor-only views, physics from the records); `lights.py` (kind 'light': PlacedLight point/spot, 'bounce' = extra PointLight (spot: a bit in front of the beam's first hit; point: towards the centroid of 6 ray hits around it; CollisionSegment vs visible geometry: objects carry entities.SURFACE_MASK in every mode, terrain/foliage the GeomNode default), counted as a second light slot and a point-shadow candidate + LightManager picking the MAX_ACTIVE nearest and lending the point/spot shadow maps; scene.frag matches the cube shadow to its light by position), `breakables.py` ('breakable' on objects and foliage groups: tool, hits, drops; breakable foliage stays live in compiled worlds, breakable objects aren't merged), `items.py` pick-up items (kind 'item', record['item']; FlashlightBeam spotlights, PlacedItem) — `controls/inventory.py` is the game hotbar / held item / axe swing (left click goes to `inventory.use()` before selection) and resource stacks; `collision.py` player colliders; `compiler.py` bake to compiled/scene.bam (+hash; shader inputs re-applied from 'flags' tags since they aren't in the bam) and the analyzer.
- Editor (`editor/`): selection is one of `selected` (WorldObject), `selected_instance` ((foliage group id, index); highlighted via a model copy under a hidden parent so it can be outlined) or `selected_collider`; `pick_object` returns an object, ('foliage', group, index) or ('collider', entity). Undo restores rebuild FoliageGroup objects, so never hold group references across undo. `editor.py` controller/UI/input (button throwers have no modifier prefixes: check Shift/Ctrl/Alt with `is_button_down`; hotkeys ignored while `widgets.typing()`), `tools.py` (File/Select/Place/Sculpt/Paint/Foliage/Water/Environment; `items()` builds the left PropertyList), `camera.py`, `overlays.py`, `undo.py` (push(label, undo, redo, merge_key)), `benchmark.py`.
- `pipeline.py`: FilterManager chain: depth prepass → `ao.frag` lighting mask (AO R, contact shadows G, sun shadow-map lookup B) → 4x4 blur → HDR MSAA scene → bloom (fast: one thresholded pass + mipmaps read in post.frag; high: 11-pass chain) → dof → `post.frag` (tonemap/grade) → `final.frag` (FXAA/sharpen/vignette/dither). Buffers are kept by reference (`ao_buffer`, `bloom_buffers`, ...) and switched off when unused. MSAA/render scale/AO res/bloom quality trigger `rebuild()`.
- `sun.py`: own shadow camera/buffer (not a Panda light); same depth texture bound twice (compare + raw) for PCF/PCSS; `sun.bind(ao_quad)` gives the mask pass its inputs. The scene shader only reads the blurred mask. `components/environment.py`: sky dome, sun + moon (separate lights; the brighter casting one owns the shadow map: `sun_casts`/`moon_casts`), hemisphere, fog, wind, snow cover, time of day; applies only when dirty.
- `shadow_cache.py`: shadow maps render only when their key (camera/light) changes, after `invalidate()` (call it when casters change), or at `gfx.shadow_update_rate` while an animated source (foliage sway, clouds) moves.
- `spot_shadow.py`: one flashlight shadow map (held beam first, else nearest on); scene.frag finds that spotlight slot by world position (`flash_shadow_position`). Shader inputs named for `trans_world_to_clip_of_<name>` must not contain underscores (`flashshadow`). It syncs in its own task (sort 45, after the update callbacks that move the player/camera, before igLoop): syncing earlier lags a frame, the position match fails and the shadow vanishes while moving.
- Flames (`components/fire.py` + `shaders/fire.*`): tongues baked once (unit cones + per-vertex 'tongue'/'flame' columns), animated in the vertex shader, `flat` face colors; parented to the campfire root. Embers are particles.py mode EMBERS (2).
- Smoke (`components/smoke.py`): continuous emitter, each puff a time offset into the same rise (the JS released all puffs at once → clump + long gap). Settings env.smoke_*; works in Panda coords.
- Footsteps (`controls/first_person.py` Footsteps): one looping sound, playing while walking (on the ground, moving, mouse captured), faded out over 60 ms on stop. Not tied to the camera bob.
- `point_shadow.py`: SLOTS (3) cube shadow maps (`make_cube_map`, distance shader; near 0.5 for the campfire like three, 0.1 for lamps); `PointShadows` hands them to the nearest shadow-casting point lights (campfires' main light + placed point lights with shadows), keeping assignments stable. scene.frag uniforms `fire_shadow_{map,position,enabled}{0,1,2}`; each light uses the map whose position matches it (0.15 m). Unused slots bind a 1x1 'no occluder' cube map (`gfx.fire_shadow*` settings).
- `shading.py`: camera masks MAIN/SHADOW/PREPASS (`set_cast_shadow`, `set_in_depth_prepass`), per-node shader inputs (`set_unlit`, `set_receive_shadow`, `set_standard_material`, `sway_amount`, terrain `paint_base`), `depth_state()`.
- Snow (`components/snow.py` SnowMap + `particles.vert` mode 0): flakes land on a top-down orthographic depth map (camera mask `SNOW_CAMERA_MASK`; `set_in_depth_prepass(False)` also hides from it, `set_snow_catcher` for the rest, e.g. held items). Life cycle per flake is computed from time + seed in the shader; landing = the FIRST crossing of the flake's (wind-slanted) path with the map, found by marching 16 steps + bisection (a fixed-point shortcut used to skip roofs and drop snow inside houses). The depth texture is 16-bit.
- Geometry: `loaders/obj.py`, `loaders/glb.py` (static), `library.py` (obj/ scan, mtl colors, npz mesh cache in .cache/), `objects.py` (model defaults + color overrides, `instance(model, colors)`), `particles.py` (GPU quads: snow, fireflies). Bird uses panda3d-gltf `Actor`.
- Shaders in `shaders/`, loaded via `shading.load_shader(vert, frag)`; `#pragma include` works (`common.glsl` wind sway, `depth_utils.glsl`).

## Conventions
- World saves are Panda coords (Z up). Only `legacy.py` keeps JS MAP data in three.js coords; convert with `coords.three_to_panda`, `rotation_y_to_heading` (JS rotateY values are radians).
- Colors are raw hex (JS r146 legacy color mode, no sRGB). Light colors = color*intensity; shader applies 1/PI.
- Comment ports with the JS file they mirror; keep code style of surrounding modules (snake_case Panda API).

## Gotchas (learned the hard way)
- `make_cube_map` faces each have a display region with Panda's grey (0.41) clear: set the clear per region, not on the buffer.
- Panda caches `p3d_Fog`: use plain uniforms (`fog_color`, `fog_density`) for anything changed at runtime.
- `gl_PointSize` is ignored (GL_PROGRAM_POINT_SIZE never enabled) → particles are vertex-shader quads.
- Depth-pass override uses `ShaderAttrib.make(shader, 100)` (priority), not an attrib override, so node inputs survive.
- Mask-pass sample rotations use a 4x4 Bayer tile and `ao_blur.frag` is a 4x4 box: keep them aligned or noise patterns return. Receiver-plane bias comes from the reconstructed face normal, not dFdx. Mask texels are snapped to one prepass pixel, the scene picks the depth-matching mask texel (3x3), and sun-facing-away surfaces store shadow/contact = 0 — otherwise lit values bleed across contact lines as a white fringe.
- The depth prepass also writes view-space normals (depth.frag); AO must use them — normals rebuilt from depth are per triangle and draw the terrain mesh onto smooth hills.
- Prepass depth texture must stay linear-filtered, or AO/contact shadows band on sloped faces.
- `direct` classes (OnscreenText, DirectGUI) are camelCase only (`setText`); DirectGUI rejects numpy floats in colors; DirectSlider echoes values as float32 (ignore tiny diffs).
- Bundled OpenAL Soft: no PipeWire backend, and its Pulse backend fails on PipeWire-Pulse ("Stream did not get ready") → silent NullAudioSounds. `app.py` sets `ALSOFT_DRIVERS=alsa,pulse,oss` before ShowBase. Tests use `audio-library-name null`, so they never catch this: check `sfxManagerList[0].is_valid()`.
- OpenAL spatializes mono only → campfire mp3 is downmixed at load (`load_mono`).
- Panda's `M_limited` clock busy-waits; the frame cap sleeps in `app._limit_frame_rate`.
- Mouse look on X11: don't warp every frame (stale pre-warp events cause shake); warp near edges, drop large deltas (`controls/mouse_look.py`).
- Don't `accept('window-event')` on the App: it replaces ShowBase's own handler (aspect ratio). Other DirectObjects may.
- DirectSlider fires its command while being constructed: widget rows start with `_updating = True` so building a panel doesn't write values (it used to set colors to black).
- Textures: MeshPart carries `uvs` (Panda v-up; glTF v flipped at load) and `texture` (absolute image path; embedded glTF images are extracted to `.cache/textures/`). OBJ reads `vt` and `map_Kd`. Object record 'texture': '' own / 'none' / 'obj/...png'. scene.frag multiplies `p3d_Texture0` (Panda binds white when untextured). Textured objects aren't merged by the compiler; foliage bakes ignore textures.
- glb.py applies node transforms except for skinned files (the JS tree). Bump `library.CACHE_VERSION` when loader output changes.
- scene.frag has 8 light slots; spotlights pass edge softness in `spotExponent`, and the campfire cube shadow applies to point lights only. F2 cycles the frame cap (F = flashlight / editor focus).
- Player physics order: walls (sideways `Colliders.resolve`, only for colliders overlapping the body), then vertical: ground (`ground_height`, tops within step) and, while rising, `ceiling_height` (head bump: stop under it, fall). Without the ceiling check a jump ended inside a box overhead and the next resolve shoved the player sideways out of it.
- The first-person camera = player position + bob offsets; keep the true position in `self.x/self.y`, never read it back from the camera.
- Color rows open `widgets.ColorPicker` (popup; textures built from numpy, live put throttled to ~15/s). `objects.instance` caches a prototype per color set, bounded at 300.
- `GeomNode.get_geom()` is const: copy with `add_geoms_from`. Python tags don't survive bam files; use string tags.
- Every active render pass costs ~50 µs of CPU even when empty: switch off unused buffers rather than leaving them idle.
